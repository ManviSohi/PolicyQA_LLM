# Synthetic Enterprise Policy Dataset

This dataset contains original synthetic policy documents used to test the document ingestion, indexing, and RAG policy Q&A experience.

Files are generated by `scripts/prepare_policy_dataset.py` and ingested by `scripts/ingest_dataset.py`.

The dataset includes policy documents covering remote work, reimbursement, information security, data retention, vendor management, anti-bribery, leave, and incident response.
